## Even or odd (only for integers)

If I ask you to write a function that checks if a number is even or odd, you might write something like this:
```ts
function isEven(n: number): boolean {
	return n % 2 === 0;
}
```

This is a valid solution but what if I tell you there is another lesser known way to do this?

Here is the solution:
```ts
function isEven(n: number): boolean {
	return n & 1 === 0;
}
function isOdd(n: number): boolean {
	return n & 1
}
```

Let's break down what is happening here but first let's approach the problem from a different angle by treating the number as a binary number instead of a decimal number.

Let's take a set of numbers and represent them in binary:
```
0: 0000
1: 0001
2: 0010
3: 0011
4: 0100
5: 0101
6: 0110
7: 0111
8: 1000
9: 1001
10: 1010
11: 1011
12: 1100
13: 1101
14: 1110
15: 1111
```
after a while you might notice a pattern: the last bit of the number is 0 if the number is even and 1 if the number is odd. This is a rule that applies to all numbers.

So the question is: how can we use this pattern to our advantage?

We can use the bitwise AND operator to check if a number is even or odd.
```ts
function isEven(n: number): boolean {
	return n & 1 === 0;
}
function isOdd(n: number): boolean {
	return n & 1;
}
```

## Flags

A common practice in low level programming is to use flags to represent a set of boolean values using a single integer. You have probably experienced a bit of this in your daily routine. One example is the `chmod` command in Linux.

However, this is not very common in high level programming languages but it is a very powerful technique that can help with performance, memory and network usage.

The concept is simple: an integer can be represented as a binary number with each bit representing a boolean value (0 or 1).

### What a high level example might look like

In practical terms we might have a object with the lights of our home and each light might be represented by a boolean value.

```ts
// Lights of my home
const lights = {
    "kitchen": false,
    "livingRoom": false,
    "bedroom": false,
    "bathroom": true,
    "porch": false,
    "garage": true,
    "garden": true
}
```
